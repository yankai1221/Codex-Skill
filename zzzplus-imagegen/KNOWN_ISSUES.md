# 未解决问题

1. **异步提交真实测试返回 HTTP 502**，没有任务 ID。无法进行真实任务查询和异步结果获取。本版只交付已测试的可配置轮询机制，不宣称异步开箱即用。
2. **服务商需确认的协议**：任务 ID JSON 路径、GET 查询 URL（含 ID 的路径/参数）、状态字段、完成/失败/取消值、结果字段结构、结果下载方式及是否同源。公开 Wokey 图片文档未给出这些细节，不能凭空补齐。取得协议后，通过 `--async-spec` 配置，无需修改 Codex 主配置。
3. **Python urllib 真实请求存在 502 差异**。Windows 自动使用已实测成功的 PowerShell；macOS/Linux 网络请求仍需在目标机器与其 Provider 实测。没有自动重试或自动失败回退，防止重复收费。
4. **实际会话覆盖无法完全自动推断**。磁盘 config.toml 不包含所有临时启动参数、托管配置及进程内状态。Skill 要求调用者确认并显式传入可信配置层/profile/非敏感覆盖，不会声称仅靠主文件就始终等于实际生效配置。
5. **OAuth/凭证助手不复用**。仅支持可安全读取的静态 API 凭证与 Provider 声明的请求头。仅有登录缓存、系统钥匙串或动态认证助手的用户需补充兼容凭证；不要求 ZZZPLUS_API_KEY，不窃取登录 token。
6. **跨域结果下载禁用**。即便是图片 CDN，也不会把 Provider 凭证发送过去。若服务商确认跨域签名下载机制，需要另行增加严格的无凭证下载支持；当前同源结果下载已实现。
7. **异步仅文生图**，不声称支持异步编辑。编辑支持 1–8 张 PNG/JPEG/WebP，不支持 mask、流式预览、一次请求多张输出或精确分辨率保证。
8. **平台实测范围**：Windows / Python 3.14 已运行；代码要求 Python 3.11+，macOS/Linux 安装和真实网络验收尚未执行。测试报告没有以模拟数据冒充这些平台成功。
